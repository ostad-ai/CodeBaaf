# CodeBaaf Sample Scripts 🧪

Welcome to the sample scripts folder! These scripts are designed to test CodeBaaf and learn Python at the same time. They are numbered from 1 to 12, going from beginner to intermediate concepts.

All scripts use only Python's built-in libraries. No external dependencies required.

## How to test these scripts in CodeBaaf:
1. Open CodeBaaf.
2. Go to `File -> Open` and select one of the scripts (e.g., `01_hello_world.py`).
3. Press **F5** (Run) or click the ▶ button to execute it in the Terminal.

## List of Tutorials:
1. **01_hello_world.py**: Basic print and variables.
2. **02_input.py**: Getting input from the user.
3. **03_math_operators.py**: Basic math operations.
4. **04_conditionals.py**: If, Elif, and Else statements.
5. **05_loops.py**: For and While loops.
6. **06_lists_tuples.py**: Working with lists and tuples.
7. **07_dictionaries.py**: Key-value pairs.
8. **08_functions.py**: Defining and calling functions.
9. **09_modules.py**: Using built-in modules like `math` and `random`.
10. **10_exceptions.py**: Try-except blocks for error handling.
11. **11_file_handling.py**: Reading and writing files.
12. **12_turtle.py**: Drawing with the built-in `turtle` module.
